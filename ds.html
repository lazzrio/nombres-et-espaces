⏱ Stratégie

Gérer 1h30

Un DS de 90 minutes se gagne autant sur la gestion du temps que sur les connaissances. Environ 4,5 minutes par point sur 20 ; on garde 5 minutes en tête pour la lecture et 5 en queue pour la relecture.

5′lecture
20′Ch. 1
15′Ch. 2
12′Ch. 3
23′Ch. 4
15′marge + relecture

Budget indicatif : à ajuster au barème réel du sujet. Les exercices de calcul d'intégrale demandent plus de temps ; les paramétrisations beaucoup moins.

1 · Lire tout, d'abord

Cinq minutes : repérer les questions « formule directe » (\(\operatorname{grad} /\operatorname{div} /\operatorname{rot}\), jacobienne, paramétrisation, domaine) et les faire en premier. Elles sécurisent des points.

2 · Règle des 8 minutes

Bloqué plus de 8 minutes sur une question : passer, laisser la place, revenir à la fin. Un exercice complet vaut plus qu'une question parfaite.

3 · Utiliser les questions précédentes

Si la question 3 demande « en déduire », utiliser le résultat de la question 2 même sans l'avoir prouvé, en le disant : « d'après 2) (admis) ».

4 · Rédiger à chaque ligne

Hypothèse du théorème, jacobien, bornes, conclusion encadrée. Chaque phrase de justification vaut des points ; chaque calcul faux n'en perd qu'un.

5 · Si ça ne colle pas

Un volume négatif, un résultat qui dépend d'une variable d'intégration : l'écrire (« incohérent, erreur probable dans … »). Cela rapporte une partie des points.

6 · Garder 5 minutes

Pour relire : signes, bornes, jacobiens, domaines, conclusions. Les erreurs de signe se repèrent à la relecture, pas pendant le calcul.

Les 5 dernières minutes : check-list

  • Chaque théorème utilisé est nommé et ses hypothèses écrites (\(C^1\), \(C^2\), étoilé, continu sur un compact).
  • Chaque changement de variables : jacobien avec valeur absolue, nouveau domaine, \(r\) ou \(r^2\sin\varphi\).
  • Chaque domaine : bornes imbriquées correctes (extérieur : constantes).
  • Chaque potentiel : vérification \(\nabla f=F\) (ou \(\overrightarrow{\mathrm{rot}}\,G=F\)).
  • Chaque limite : « pas de limite » = deux chemins ; « limite » = majoration.
  • Chaque résultat final : forme exacte, simplifiée, encadrée, plausible (signe, ordre de grandeur).
📄 Fiche de survie

Ce qu'il faut pouvoir écrire de tête

Les formules et réflexes des quatre chapitres sur une page. Recopie-la de mémoire à \(J-1\), puis compare.

Chapitre 1 · Fonctions de plusieurs variables

  • Limite en \((0,0)\) : réfuter = deux chemins (\(y=0\), \(x=0\), \(y=x\), \(y=x^2\)) ; prouver = \(|f-\ell|\le g\to0\) ou polaires avec borne indépendante de \(\theta\). \(2|xy|\le x^2+y^2\).
  • Continu : limite \(=\) valeur. Prolongement : on pose la valeur égale à la limite.
  • \(C^1\) en 4 temps : (1) \(C^1\) hors de \(0\), (2) continuité, (3) dérivées en \(0\) par définition \(\frac{f(h,0)-f(0,0)}h\), (4) continuité des dérivées.
  • Schwarz : \(f\in C^2\) sur un ouvert \(\Rightarrow\partial_x(\partial_yf)=\partial_y(\partial_xf)\).
  • Jacobienne : ligne \(i\) = \(\nabla f_i\) ; \(J_{g\circ f}(a)=J_g(f(a))\,J_f(a)\).
  • EDP : « \(+C\) » = fonction de l'autre variable. Polaires : \(xf_x+yf_y=rF_r\), \(xf_y-yf_x=F_\theta\).
  • Taylor 2 : \(f+hf_x+kf_y+\tfrac12(h^2f_{xx}+2hkf_{xy}+k^2f_{yy})+o(\cdot)\).

Chapitre 2 · Opérateurs vectoriels

  • \(\nabla f=(f_x,f_y,f_z)\) ; \(\operatorname{div}F=\partial_xF_1+\partial_yF_2+\partial_zF_3\) ; \(\Delta f=\operatorname{div}\nabla f\).
  • \(\overrightarrow{\mathrm{rot}}\,F=(\partial_yF_3-\partial_zF_2,\ \partial_zF_1-\partial_xF_3,\ \partial_xF_2-\partial_yF_1)\).
  • \(\overrightarrow{\mathrm{rot}}\nabla f=\vec0\), \(\operatorname{div}\overrightarrow{\mathrm{rot}}\,F=0\) (classe \(C^2\), Schwarz).
  • Potentiel scalaire : \(F\in C^1\), \(\overrightarrow{\mathrm{rot}}\,F=\vec0\), ouvert étoilé \(\Rightarrow\) existe. Intégrer \(F_1\) en \(x\) (\(+C(y,z)\)), identifier, vérifier \(\nabla f=F\).
  • Potentiel vecteur : \(\operatorname{div}F=0\), étoilé. \(G=(X,Y,0)\) : \(\overrightarrow{\mathrm{rot}}\,G=(-\partial_zY,\ \partial_zX,\ \partial_xY-\partial_yX)\).
  • Étoilé : convexe \(\checkmark\) ; \(\mathbb{R}^2\setminus\{0\}\), couronne \(\times\).
  • Radial : \(\Delta f(r)=f''+\frac2rf'\) ; \(\Delta\frac1r=0\) ; \(\operatorname{div}\frac X{r^3}=0\).

Chapitre 3 · Paramétrisations

  • Segment \(A+t(B-A)\), \(t\in[0,1]\) ; cercle \((\Omega_1+R\cos t,\Omega_2+R\sin t)\) ; ellipse \((\Omega_1+a\cos t,\Omega_2+b\sin t)\) ; sens direct = anti-horaire.
  • Droite = deux plans : un paramètre libre, ou \(\vec n_1\wedge\vec n_2\) + un point.
  • Compléter les carrés : même signe \(\to\) ellipse (second membre \(>0\), sinon vide) ; signes opposés \(\to\) hyperbole ; un seul carré \(\to\) parabole.
  • Sphère : \(R^2=\frac{a^2+b^2+c^2}4-d\) ; boule \(\le R^2\).
  • Quadriques : variable linéaire \(\to\) paraboloïde ; signe \(-\) sans terme linéaire \(\to\) cône ; trois carrés \(=\) cte \(\to\) ellipsoïde ; variable absente \(\to\) cylindre.
  • Cylindriques \((r,\theta,z)\) ; sphériques \(x=r\sin\varphi\cos\theta\), \(y=r\sin\varphi\sin\theta\), \(z=r\cos\varphi\) (\(\varphi\in[0,\pi]\) depuis \(Oz\)).

Chapitre 4 · Intégrales multiples

  • Fubini : \(f\) continue sur un compact ; type 1 : \(a\le x\le b\), \(y_1(x)\le y\le y_2(x)\) ; bornes extérieures constantes.
  • Polaires : \(dx\,dy=r\,dr\,d\theta\) ; \(x^2+y^2\le2ax\iff r\le2a\cos\theta\), \(\theta\in[-\frac\pi2,\frac\pi2]\).
  • Ellipse : \(x=ar\cos\theta\), \(y=br\sin\theta\), jacobien \(abr\). Changement \(u,v\) : \(|\partial(x,y)/\partial(u,v)|\) (inverser si besoin).
  • Cylindriques \(dV=r\,dr\,d\theta\,dz\) ; sphériques \(dV=r^2\sin\varphi\,dr\,d\theta\,d\varphi\) ; ellipsoïde : \(abc\,r^2\sin\varphi\).
  • Symétrie + parité \(\Rightarrow0\). Volume \(=\iiint1\) ; aire \(=\iint1\).
  • \(\int_0^{2\pi}\cos^2=\pi\) ; \(\int_0^{2\pi}\cos^4=\frac{3\pi}4\) ; \(\int_0^\pi\sin^3=\frac43\) ; \(\int_0^\pi\sin^4=\frac{3\pi}8\).

Rédaction

  • 4 temps : annoncer, justifier les hypothèses, calculer, conclure (encadré).
  • Toujours écrire : le domaine ; « de classe \(C^k\) sur … comme somme, produit, quotient, composée » ; le nom du théorème ; le jacobien et le nouveau domaine ; les bornes ; la vérification (\(\nabla f=F\), aire \(>0\)).
  • Jamais : « évident » ; limite sur quelques chemins \(\Rightarrow\) existence ; « \(+C\) » en EDP à deux variables ; jacobien oublié ; formule dérivée utilisée en un point de recollement.
