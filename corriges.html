Géométrie du plan et de l'espace

Outils utilisés : produit scalaire (orthogonalité, normes), produit vectoriel (normale, colinéarité, aire), produit mixte, équations de droites et de plans. Revoir le cours (ch. 0)

Ex 1

Produits scalaires de vecteurs orthogonaux

u, v ∈ ℝ² orthogonaux, ‖u‖ = 4, ‖v‖ = 5. Calculer (u+v)², (u−v)², (u+v)·(u−v). Trouver x tel que a) (xu+v)·(u+v) = 13 ; b) (xu−v)·(xu−v) = 23.
💡 Méthode
Ne jamais chercher de coordonnées : développer par bilinéarité, puis remplacer u·u = ‖u‖² = 16, v·v = 25 et u·v = 0 (orthogonaux). La notation (w)² signifie w·w = ‖w‖².
✅ Correction détaillée
  1. Les trois produits
    (u+v)² = u·u + 2 u·v + v·v = 16 + 0 + 25 = 41 (u−v)² = u·u − 2 u·v + v·v = 16 − 0 + 25 = 41 (u+v)·(u−v) = u·u − v·v = 16 − 25 = −9
    Les deux premiers sont égaux : c'est Pythagore (diagonales d'un rectangle de même longueur).
  2. a) Équation du premier degré
    (xu+v)·(u+v) = x u·u + x u·v + v·u + v·v = 16x + 25 = 13 ⟹ x = −12/16 = −3/4
  3. b) Équation du second degré
    (xu−v)·(xu−v) = x² u·u − 2x u·v + v·v = 16x² + 25 = 23 ⟹ 16x² = −2
    Impossible dans ℝ. Interprétation : ‖xu − v‖² = ‖xu‖² + ‖v‖² ≥ 25 > 23 (Pythagore).
Réponse41 ; 41 ; −9. a) x = −3/4. b) aucun réel x ne convient.
PiègeRépondre « x = ±√(−2/16) » : une norme au carré est toujours ≥ 0, dire clairement « pas de solution réelle ».
Ex 2

Équations cartésiennes de droites du plan

1. Équation de la droite D passant par A(3, 4) et B(6, −2). Le point C(2, 10/3) est-il sur D ? 2. Équation de la droite perpendiculaire à 2x + 3y − 1 = 0 passant par A(1, −1).
💡 Méthode
Une droite du plan ax + by + c = 0 a pour vecteur normal (a, b) et pour vecteur directeur (−b, a). On obtient donc l'équation à partir d'un vecteur directeur en « échangeant et changeant un signe », puis on trouve c avec un point.
✅ Correction détaillée
  1. 1. Vecteur directeur et normale
    AB = (6−3, −2−4) = (3, −6) ∝ (1, −2) ⟹ normale n = (2, 1) D : 2x + y + c = 0, avec A : 6 + 4 + c = 0 ⟹ c = −10 D : 2x + y − 10 = 0 (contrôle B : 12 − 2 − 10 = 0 ✓)
  2. Le point C
    2·2 + 10/3 − 10 = −8/3 ≠ 0 ⟹ C ∉ D
  3. 2. Perpendiculaire à 2x + 3y − 1 = 0
    La normale (2, 3) de la droite donnée devient le vecteur directeur de la perpendiculaire ; sa normale est donc (3, −2) :
    Δ : 3x − 2y + c = 0, avec A(1, −1) : 3 + 2 + c = 0 ⟹ c = −5 Δ : 3x − 2y − 5 = 0 contrôle : direction de Δ = (2, 3), direction de la droite donnée = (3, −2) ; 2·3 + 3·(−2) = 0 ✓
RéponseD : 2x + y − 10 = 0, C ∉ D. Perpendiculaire : 3x − 2y − 5 = 0.
Ex 3

Ensembles définis avec des valeurs absolues

Représenter l'ensemble des points M(x, y) tels que : 1. 2x + |y| − 1 = 0 ; 2. |x| + |y| = 1 ; 3. max(|x|, |y|) = 1.
💡 Méthode
Une valeur absolue = deux cas selon le signe. On découpe le plan par quadrants (ou demi-plans), on obtient des morceaux de droites, puis on exploite les symétries : |y| ne change pas si y → −y (symétrie par rapport à Ox), |x| ne change pas si x → −x (symétrie par rapport à Oy).
✅ Correction détaillée
  1. 1. 2x + |y| − 1 = 0 ⟺ |y| = 1 − 2x
    Il faut 1 − 2x ≥ 0, soit x ≤ 1/2. Pour y ≥ 0 : y = 1 − 2x ; pour y ≤ 0 : y = 2x − 1. Ce sont deux demi-droites issues du point (1/2, 0), passant par (0, 1) et (0, −1) : un chevron « < » symétrique par rapport à Ox.
  2. 2. |x| + |y| = 1
    Quadrant x, y ≥ 0 : x + y = 1 (segment de (1,0) à (0,1)). Par symétrie par rapport aux deux axes : les 4 segments −x + y = 1, −x − y = 1, x − y = 1. C'est un carré « sur la pointe » (losange) de sommets (±1, 0), (0, ±1).
  3. 3. max(|x|, |y|) = 1
    Soit |x| = 1 et |y| ≤ 1 (côtés verticaux x = ±1), soit |y| = 1 et |x| ≤ 1 (côtés horizontaux y = ±1) : le carré de sommets (±1, ±1), de côté 2.
À savoir|x| + |y| = 1 et max(|x|, |y|) = 1 sont les « cercles unités » des normes ‖·‖₁ et ‖·‖∞ ; x² + y² = 1 est celui de la norme euclidienne ‖·‖₂.
Ex 4

Produits scalaire et vectoriel, projections, orthogonalité, colinéarité

Calculer u·v et u∧v pour : 1. u(4, 1, 3), v(−2, −1, 5) ; 2. u(1, 0, 3), v(−1, 4, −3), ainsi que les projetés vu et uv ; 3. u(a, a+1, 4), v(a+1, a, −1) : pour quels a sont-ils orthogonaux ? colinéaires ?
💡 Méthode
u∧v = (u₂v₃ − u₃v₂, u₃v₁ − u₁v₃, u₁v₂ − u₂v₁) (cycle 1→2→3). Projeté orthogonal de v sur u : vu = (u·v/‖u‖²) u. Orthogonaux ⟺ u·v = 0 ; colinéaires ⟺ u∧v = 0 (les 3 composantes nulles en même temps).
✅ Correction détaillée
  1. 1.
    u·v = 4·(−2) + 1·(−1) + 3·5 = −8 − 1 + 15 = 6 u∧v = (1·5 − 3·(−1), 3·(−2) − 4·5, 4·(−1) − 1·(−2)) = (8, −26, −2)
    Contrôle : (8, −26, −2)·u = 32 − 26 − 6 = 0 ✓ (le produit vectoriel est orthogonal à u).
  2. 2.
    u·v = −1 + 0 − 9 = −10 u∧v = (0·(−3) − 3·4, 3·(−1) − 1·(−3), 1·4 − 0) = (−12, 0, 4) ‖u‖² = 10 ⟹ v_u = (−10/10) u = −u = (−1, 0, −3) ‖v‖² = 26 ⟹ u_v = (−10/26) v = (5/13, −20/13, 15/13)
  3. 3. Orthogonalité
    u·v = a(a+1) + (a+1)a − 4 = 2a² + 2a − 4 = 2(a − 1)(a + 2) = 0 ⟺ a = 1 ou a = −2
  4. 3. Colinéarité
    u∧v = ((a+1)(−1) − 4a, 4(a+1) + a, a² − (a+1)²) = (−5a − 1, 5a + 4, −2a − 1)
    La 3e composante s'annule seulement pour a = −1/2 ; la 1re vaut alors 3/2 ≠ 0. Les trois ne sont jamais nulles ensemble : jamais colinéaires.
Réponse1. 6 ; (8, −26, −2). 2. −10 ; (−12, 0, 4) ; vu = (−1, 0, −3), uv = (5, −20, 15)/13. 3. orthogonaux pour a ∈ {1, −2} ; jamais colinéaires.
Ex 5

Double produit vectoriel et produit mixte

A = ex + ey, B = ex + 2ey, C = 2ex + ey. 1. Comparer (A∧B)∧C et A∧(B∧C). 2. Comparer A·(B∧C) et (A∧B)·C.
💡 Méthode
Calcul direct en coordonnées (A = (1,1,0), B = (1,2,0), C = (2,1,0)), puis contrôle par la formule du double produit vectoriel a∧(b∧c) = (a·c)b − (a·b)c (hors programme mais très utile en électromagnétisme).
✅ Correction détaillée
A∧B = (0, 0, 1·2 − 1·1) = (0, 0, 1) (A∧B)∧C = (0,0,1)∧(2,1,0) = (−1, 2, 0) B∧C = (0, 0, 1·1 − 2·2) = (0, 0, −3) A∧(B∧C) = (1,1,0)∧(0,0,−3) = (−3, 3, 0)

Les deux résultats diffèrent : le produit vectoriel n'est pas associatif. Contrôle : (A·C)B − (A·B)C = 3(1,2,0) − 3(2,1,0) = (−3, 3, 0) ✓.

A·(B∧C) = (1,1,0)·(0,0,−3) = 0 (A∧B)·C = (0,0,1)·(2,1,0) = 0

Égaux, comme toujours (c'est le produit mixte [A, B, C]), et nuls parce que les trois vecteurs sont dans le plan (xOy) : ils sont coplanaires, le parallélépipède est plat.

Réponse(−1, 2, 0) ≠ (−3, 3, 0) ; produits mixtes égaux à 0.

Ex 1

Domaines de définition et limites en (0, 0)

1) f = xy/(x² + y² + 2) ; 2) f = (x − y)²/(x² + y²) ; 3) f = sin(xy)/(xy) ; 4) f = x²y²/(x² + y²).
💡 Méthode
1) Si f est définie et continue en (0,0), la limite est f(0,0). 2) Sinon comparer les degrés : numérateur de même degré que le dénominateur → probablement pas de limite (deux chemins) ; degré plus grand → probablement 0 (majorer). 3) Une forme connue en une variable (sin t / t) : poser t = xy.
✅ Correction détaillée
  1. 1) D = ℝ², limite 0
    x² + y² + 2 ≥ 2 > 0 : f est définie et continue sur ℝ² (quotient de fonctions continues à dénominateur non nul), donc lim = f(0,0) = 0/2 = 0.
  2. 2) D = ℝ² \ {(0,0)}, pas de limite
    y = 0 : f(x, 0) = x²/x² = 1 → 1 y = x : f(x, x) = 0 → 0
    Deux chemins, deux valeurs : pas de limite. (En polaires : f = (cos θ − sin θ)² = 1 − sin 2θ dépend de θ.)
  3. 3) D = {(x, y) : xy ≠ 0} (le plan privé des deux axes), limite 1
    Quand (x, y) → (0, 0), t = xy → 0, et sin t / t → 1. Plus rigoureusement : |sin t − t| ≤ |t|³/6 donne |f − 1| ≤ (xy)²/6 → 0. Limite 1 (f se prolonge même par continuité à tous les axes par la valeur 1).
  4. 4) D = ℝ² \ {(0,0)}, limite 0
    x² ≤ x² + y² ⟹ |f| = y² · x²/(x² + y²) ≤ y² → 0
    Théorème des gendarmes : limite 0. (Polaires : f = r² cos²θ sin²θ, |f| ≤ r².)
Réponse1) ℝ², 0. 2) ℝ²*, pas de limite. 3) plan privé des axes, 1. 4) ℝ²*, 0.
Ex 2

Calcul de dérivées partielles

1) xy ; 2) exy ; 3) x cos x cos y ; 4) (x² + y²)/(x² − y²) ; 5) √(1 + x²y²) ; 6) (x² + y²) ln(x² + y²).
💡 Méthode
Pour ∂f/∂x : y est une constante, on applique les règles d'une variable (produit, quotient, composée). Toujours préciser le domaine où le calcul est valable.
✅ Correction détaillée
1) ℝ² : ∂x f = y ∂y f = x 2) ℝ² : ∂x f = y e^(xy) ∂y f = x e^(xy) 3) ℝ² : ∂x f = (cos x − x sin x) cos y ∂y f = −x cos x sin y 4) y ≠ ±x : ∂x f = [2x(x²−y²) − (x²+y²)·2x]/(x²−y²)² = −4xy²/(x²−y²)² ∂y f = [2y(x²−y²) + (x²+y²)·2y]/(x²−y²)² = 4x²y/(x²−y²)² 5) ℝ² (1 + x²y² ≥ 1) : ∂x f = 2xy²/(2√(1+x²y²)) = xy²/√(1+x²y²) ∂y f = x²y/√(1+x²y²) 6) ℝ² \ {0} : ∂x f = 2x ln(x²+y²) + (x²+y²)·2x/(x²+y²) = 2x(ln(x²+y²) + 1) ∂y f = 2y(ln(x²+y²) + 1)

Ex 3

Continuité, dérivées partielles, classe C¹ (fonctions prolongées en 0)

1) f(x, y) = y³/√(x² + y⁴) si (x, y) ≠ (0, 0), f(0, 0) = 0. 2) f(x, y) = (x³ − y³)/(x² + y²) si (x, y) ≠ (0, 0), f(0, 0) = 0. Étudier la continuité de f, l'existence et la continuité des dérivées partielles. f est-elle C¹ sur ℝ² ?
💡 Méthode (le plan en 4 temps, toujours le même)
(a) Hors de (0,0) : f est C¹ comme quotient/composée de fonctions C¹ (dénominateur non nul). (b) Continuité en 0 : majorer |f − f(0,0)|. (c) Dérivées partielles en 0 par la définition (taux d'accroissement), jamais en dérivant la formule. (d) Continuité de ∂f/∂x en 0 : comparer la limite de la formule avec la valeur trouvée en (c) ; un chemin qui donne autre chose suffit pour conclure « non C¹ ».
✅ Correction détaillée

1) f = y³/√(x² + y⁴)

  1. Continuité en (0,0)
    x² + y⁴ ≥ y⁴ donne √(x² + y⁴) ≥ y², donc pour y ≠ 0 :
    |f| ≤ |y|³/y² = |y| → 0 (et f = 0 si y = 0)
    f est continue en 0, donc sur ℝ².
  2. Dérivées partielles en (0,0) par la définition
    ∂x f(0,0) = lim (f(h,0) − 0)/h = lim 0/h = 0 ∂y f(0,0) = lim (f(0,k) − 0)/k = lim (k³/k²)/k = 1
  3. Dérivées hors de (0,0)
    ∂x f = −x y³/(x² + y⁴)^(3/2) ∂y f = (3x²y² + y⁶)/(x² + y⁴)^(3/2)
  4. Continuité des dérivées en 0 : le chemin x = y²
    ∂x f(y², y) = −y⁵/(2y⁴)^(3/2) = −1/(2√2 |y|) · signe(y) → ±∞ ∂y f(y², y) = 4y⁶/(2√2 |y|⁶) = √2 ≠ 1 = ∂y f(0,0)
    Aucune des deux dérivées partielles n'est continue en (0,0).
Conclusion 1)f est continue sur ℝ², admet des dérivées partielles partout, mais n'est pas C¹ sur ℝ² (seulement sur ℝ² \ {0}).

2) f = (x³ − y³)/(x² + y²)

  1. Continuité en 0 (polaires)
    f = r (cos³θ − sin³θ), |f| ≤ 2r → 0
  2. Dérivées en 0
    ∂x f(0,0) = lim (h³/h²)/h = 1 ∂y f(0,0) = lim (−k³/k²)/k = −1
  3. Dérivées hors de 0 et continuité
    ∂x f = (x⁴ + 3x²y² + 2xy³)/(x² + y²)² ∂y f = −(y⁴ + 3x²y² + 2x³y)/(x² + y²)² polaires : ∂x f = cos⁴θ + 3cos²θ sin²θ + 2 cos θ sin³θ (ne dépend que de θ) θ = 0 → 1 ; θ = π/2 → 0
    ∂x f n'a pas de limite en 0 : elle n'est pas continue en (0,0).
Conclusion 2)f continue sur ℝ², dérivées partielles partout (1 et −1 en 0), pas C¹ sur ℝ².
Pour aller plus loin2) f n'est même pas différentiable en 0 : f(h, k) − (h − k) = hk(h − k)/(h² + k²) et, divisé par √(h² + k²), ce reste vaut −1/√2 le long de k = −h au lieu de tendre vers 0. Leçon : dérivées partielles en un point ⇏ différentiable.
Ex 4

Dérivées partielles secondes (et troisièmes pour la 3)

1) 2xy/(x² + y²)², (x, y) ≠ (0,0) ; 2) f(x, y, z) = ez + 1/x + x e−y, x ≠ 0 ; 3) cos(xy²) ; 4) 1/(cos²x + e−y).
💡 Méthode
Calculer proprement les dérivées premières et les factoriser avant de redériver. Grâce à Schwarz (fonctions C² sur leur domaine), une seule dérivée croisée suffit — mais la calculer des deux façons est un excellent contrôle.
✅ Correction détaillée

1) f = 2xy D⁻² avec D = x² + y²

∂x f = 2y D⁻² − 8x²y D⁻³ = 2y(y² − 3x²)/D³ ∂y f = 2x(x² − 3y²)/D³ ∂²f/∂x² = 24xy(x² − y²)/D⁴ ∂²f/∂y² = −24xy(x² − y²)/D⁴ ∂²f/∂x∂y = ∂²f/∂y∂x = −6(x⁴ − 6x²y² + y⁴)/D⁴

Remarque : ∂²f/∂x² + ∂²f/∂y² = 0, f est harmonique.

2) f = ez + x⁻¹ + x e−y

∂x f = −1/x² + e^(−y) ∂y f = −x e^(−y) ∂z f = e^z ∂²f/∂x² = 2/x³ ∂²f/∂y² = x e^(−y) ∂²f/∂z² = e^z ∂²f/∂x∂y = −e^(−y) ∂²f/∂x∂z = 0 ∂²f/∂y∂z = 0

3) f = cos(xy²)

∂x f = −y² sin(xy²) ∂y f = −2xy sin(xy²) ∂²f/∂x² = −y⁴ cos(xy²) ∂²f/∂y² = −2x sin(xy²) − 4x²y² cos(xy²) ∂²f/∂x∂y = −2y sin(xy²) − 2xy³ cos(xy²) ∂³f/∂x³ = y⁶ sin(xy²) ∂³f/∂x²∂y = −4y³ cos(xy²) + 2xy⁵ sin(xy²) ∂³f/∂x∂y² = −2 sin(xy²) − 10xy² cos(xy²) + 4x²y⁴ sin(xy²) ∂³f/∂y³ = −12x²y cos(xy²) + 8x³y³ sin(xy²)

    f_x = 3y − 6x = 0 ⟹ y = 2x ; f_y = 3x − 3y² = 0 ⟹ x = 4x² ⟹ x ∈ {0, 1/4} (0, 0) : r = −6, s = 3, t = 0 ; Δ = −9 → col, f = 0 (1/4, 1/2) : r = −6, s = 3, t = −6y = −3 ; Δ = 9 > 0, r < 0 → max local, f = 1/16
  4. 3. bord et conclusion
    g(t) = 3 cos t sin t − 3 cos²t − sin³t n'a pas de racines « jolies » pour g'(t) = 0 : on les obtient numériquement (calculatrice, ou Python scipy.optimize.minimize_scalar).
    max du bord ≈ 1,457 en (−0,293 ; −0,956) min du bord ≈ −3,690 en (−0,899 ; 0,439)
    Le max local intérieur 1/16 est battu par le bord : max global ≈ 1,457, min global ≈ −3,69, tous deux sur le cercle.
PiègeUn maximum local intérieur n'est pas forcément le maximum global : toujours comparer avec le bord.

Ex 5

Extrema locaux et globaux (6 fonctions)

1. x² + xy + y² + x³/4 ; 2. x⁴ + y⁴ ; 3. x³ + y³ ; 4. 4xy + 1/x + 1/y ; 5. x ln y − y ln x ; 6. (y² − x²)(y² − 2x²).
✅ Correction détaillée
  1. 1. x² + xy + y² + x³/4
    f_y = x + 2y = 0 ⟹ y = −x/2 ; f_x = 2x + y + 3x²/4 = 3x/2 + 3x²/4 = 0 ⟹ x ∈ {0, −2} (0, 0) : r = 2, s = 1, t = 2 ; Δ = 3 > 0 → min local, f = 0 (−2, 1) : r = 2 + 3x/2 = −1, s = 1, t = 2 ; Δ = −3 → col
    Aucun extremum global : f(x, 0) = x² + x³/4 → ±∞ quand x → ±∞.
  2. 2. x⁴ + y⁴
    Seul point critique (0, 0), Δ = 0 (Hessienne nulle). Mais f ≥ 0 = f(0, 0) : minimum global (strict). Pas de max.
  3. 3. x³ + y³
    Seul point critique (0, 0), Δ = 0. f(t, 0) = t³ change de signe : pas d'extremum.
  4. 4. 4xy + 1/x + 1/y
    4y = 1/x², 4x = 1/y² ⟹ x = y = 4^(−1/3) r = 2/x³ = 8, t = 8, s = 4 ; Δ = 48 > 0 → min local, f = 3·4^(1/3) = 3∛4 ≈ 4,76
    Sur le quart de plan x, y > 0, c'est même le minimum global : par l'inégalité arithmético-géométrique, 4xy + 1/x + 1/y ≥ 3 ∛(4xy · 1/x · 1/y) = 3∛4. Sur tout le domaine, pas de min global (f → −∞ quand x → 0⁻).
  5. 5. x ln y − y ln x (x, y > 0)
    f_x = ln y − y/x = 0, f_y = x/y − ln x = 0 Posons u = y/x : ln y = u et ln x = 1/u, donc u = y/x = e^(u − 1/u), soit ln u = u − 1/u h(u) = u − 1/u − ln u a pour dérivée (u² − u + 1)/u² > 0 et h(1) = 0 ⟹ u = 1, x = y = e r = y/x² = 1/e, t = −x/y² = −1/e, s = 1/y − 1/x = 0 ; Δ = −1/e² < 0 → col en (e, e)
    Aucun extremum.
  6. 6. (y² − x²)(y² − 2x²)
    ∇f = (2x(4x² − 3y²), 2y(2y² − 3x²)) = 0 ⟹ (0, 0) seulement ; Δ = 0 (degré 4). Étude du signe : f(x, 0) = 2x⁴ > 0, mais sur y² = 1,5 x² (entre les deux paires de droites), f = (0,5 x²)(−0,5 x²) < 0. Dans tout voisinage de O, f prend les deux signes : pas d'extremum en (0, 0).
Ex 6

Extrema sous contraintes (Lagrange)

1. x − y + z sur x² + y² + z² = 2 ; 2. x − y sur x² − y² = 2 ; 3. x + y + z sous x² − y² = 1 et 2x + z = 1.
💡 Méthode
Lagrange : aux extrema de f sur {g = 0} (avec ∇g ≠ 0), ∇f = λ∇g. Avec deux contraintes : ∇f = λ∇g₁ + μ∇g₂, ou plus simplement éliminer une variable grâce à la contrainte linéaire. Attention : Lagrange donne des candidats ; l'existence du max/min vient d'un argument de compacité (sphère) ou d'une étude directe.
✅ Correction détaillée
  1. 1. Sphère (compacte) : max et min existent
    (1, −1, 1) = 2λ(x, y, z) ⟹ (x, y, z) = (1/2λ)(1, −1, 1) x² + y² + z² = 3/(4λ²) = 2 ⟹ 1/(2λ) = ±√(2/3) points ±√(2/3)(1, −1, 1) : f = ±3√(2/3) = ±√6
    max √6, min −√6. Contrôle Cauchy-Schwarz : |f| = |(1, −1, 1)·(x, y, z)| ≤ √3 · √2 = √6.
  2. 2. Hyperbole (non bornée)
    (1, −1) = λ(2x, −2y) ⟹ 2λx = 1 = 2λy ⟹ x = y, incompatible avec x² − y² = 2. Aucun extremum. En effet x − y = 2/(x + y) prend, sur chaque branche, toutes les valeurs d'un intervalle ouvert ]0, +∞[ ou ]−∞, 0[, sans les atteindre aux bornes.
  3. 3. Éliminer z = 1 − 2x
    f = 1 − x + y sous x² − y² = 1. Lagrange : (−1, 1) = λ(2x, −2y) ⟹ x = y, incompatible avec x² − y² = 1 : aucun extremum (y − x = −1/(x + y) ne fait que tendre vers 0 ou l'infini).

Ex 9

Pavé de volume fixé, surface minimale

Montrer qu'un pavé de volume V fixé a une surface minimale quand c'est un cube.
💡 Méthode
Arêtes x, y, z > 0, xyz = V, S = 2(xy + yz + zx). Deux voies : Lagrange, ou (plus court) inégalité arithmético-géométrique sur les trois produits xy, yz, zx.
✅ Correction détaillée
IAG : (xy + yz + zx)/3 ≥ ∛(xy · yz · zx) = ∛(V²) ⟹ S ≥ 6 V^(2/3), avec égalité ⟺ xy = yz = zx ⟺ x = y = z = ∛V (cube) Lagrange : 2(y + z) = λyz, 2(x + z) = λxz ⟹ en soustrayant, 2(y − x) = λz(y − x) ; si x ≠ y alors λz = 2, puis 2(y + z) = 2y ⟹ z = 0, impossible. Donc x = y, de même y = z.
RéponseSmin = 6V2/3, atteinte pour le cube d'arête ∛V.
Ex 10

Boîte sans couvercle de surface 16 m²

Dimensions d'une boîte rectangulaire sans couvercle de surface 16 m² et de volume maximal.
💡 Méthode
Base x × y, hauteur z : surface g = xy + 2xz + 2yz = 16 (un fond, quatre côtés), volume V = xyz. Lagrange ∇V = λ∇g, puis exploiter la symétrie x ↔ y.
✅ Correction détaillée
yz = λ(y + 2z), xz = λ(x + 2z), xy = λ(2x + 2y) (1)·x − (2)·y : 2λz(x − y) = 0 ⟹ x = y (3) : x² = 4λx ⟹ λ = x/4 ; (1) : xz = (x/4)(x + 2z) ⟹ z = x/2 contrainte : x² + 2x·(x/2)·2 = 3x² = 16 ⟹ x = y = 4/√3 ≈ 2,31 m, z = 2/√3 ≈ 1,15 m V = x²z = (16/3)(2/√3) = 32√3/9 ≈ 6,16 m³
Contrôle sans calculRecollons la boîte à sa symétrique par rapport au plan du couvercle : on obtient un pavé fermé x × y × 2z, de surface 32 et de volume 2V.
